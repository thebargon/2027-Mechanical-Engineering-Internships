# Test fixtures

`greenhouse.json` is a synthetic response shaped like the Greenhouse jobs API. The `.example` employer links are test data.

`spacex.json` is a five-record excerpt from the repository's existing `scripts/tmp_spacex_job_posts_new.json` snapshot, originally obtained from the public SpaceX CMS feed. It tests rejection of international and software roles; it is not current vacancy data. Positive SpaceX link tests use synthetic IDs in the test file.
